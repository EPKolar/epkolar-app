### v3.9.825 — Swipe im Browser (touch-action)
**Symptom:** Wischen ging nur als **installierte (standalone) PWA**, nicht im Browser-Tab.
**Root Cause (code-level, keine Spekulation):** Der `useSwipe`-Hook (~6002) fängt horizontale
Wische über `onTouchStart`/`onTouchEnd` **ohne `preventDefault`**. Ohne `touch-action:pan-y`
auf dem Wisch-Container behandelt der **Browser** die horizontale Geste selbst
(Page-Scroll / History-Navigation) → der Hook sieht nie eine saubere Geste. Standalone gibt
es diese konkurrierenden Browser-Gesten nicht → derselbe Code lief.
`.main-pad` (mainSwipe) hatte den Constraint schon seit **v3.9.313** (mit genau dieser
Begründung im Kommentar); die **zwei anderen** useSwipe-Flächen blieben ohne:
- `shellSwipe` (Projekt-interne Navigation dashboard/zeit/berichte/…, ~14905)
- `absSwipe` (Urlaubs-Tabs, ~21250)

**Fix:** `touchAction:"pan-y"` auf beide Container (zwei inline-Styles). Keine Logik/Schema/Auth.
**Beleg:** Playwright computed `touch-action` — kaputt=`auto`, Fix=`pan-y`, Referenz(`.main-pad`)=`pan-y`
→ Fix verhaltensgleich zur funktionierenden Fläche. Test `tests/test_swipe_touchaction.py`
(Invariante: **jede** useSwipe-Fläche muss `pan-y` tragen; deckt alle 3 Callsites + Zähler ab).

### v3.9.826 — Büro macht die Einteilung
**Symptom:** Büro (`buero`) sah bei den Arbeitsscheinen keinen Monteurs-Kalender / keine Timeline.
**Root Cause:** `ArbeitsscheinView` (~9882) definierte `isAdmin` als `admin||projektleiter` — **`buero` fehlte** (9884).
Der **Dispo-Tab war für buero schon offen** (10457, explizite Liste `admin/buero/projektleiter`),
aber der Kalender-Monteur-Auswähler (10655) hängt an `isAdmin` und fällt für Nicht-Admin auf ein
festes Badge der **eigenen** monteurId zurück → buero (ohne monteurId) sah leeren Kalender, keine
Monteurs-Auswahl. `canSync` (9885) enthielt buero längst; 9884 war die vergessene Stelle.
**Fix:** `buero` in `ArbeitsscheinView.isAdmin` → Kalender-Monteur-Auswähler + Monteur-/SB-Filter +
Dispo-Inhalt wie admin/PL. **`isMonteurRole` bleibt `monteur/helfer`** → die `isMonteurRole&&!isAdmin`-
Schutzriegel ändern sich für buero **nicht** (buero war nie Monteur; geprüft: alle isAdmin-Nutzungen
in der Komponente sind View/Filter/Select, nichts destruktiv-Admin-only). Analog Abwesenheiten-`isAdmin`
(v3.9.453). Test `tests/test_buero_as_dispo.py` (isAdmin enthält buero; isMonteurRole NICHT; Dispo-Tab-Liste bleibt).
